# Рассылка по сделкам Битрикс24 — инструкция для ассистента

Когда пользователь просит «найти сделки по условиям и отправить им письмо»:

1. Создай/обнови файл кампании в `campaigns/` (фильтр в секции `[filter]`, тема, текст письма
   в `templates/`). Не зашивай условия в код. Если неясно, как называется поле, воронка
   или стадия, запусти `python -m bitrix_mailer fields`.
2. Запусти предпросмотр **без отправки**:
   `python -m bitrix_mailer preview campaigns/<файл>.toml --no-prompt`
   (дополнительные условия — флагами `-w "Сумма>100000"`).
3. Покажи пользователю статистику целиком (найдено / с контактами / с валидным email /
   уже получали / будет отправлено), причины исключения и пример письма.
4. **Жди явного подтверждения** пользователя. Без него `send` не запускать.
5. После подтверждения: `python -m bitrix_mailer send <id> --yes`.
6. Покажи итоговый отчёт (`python -m bitrix_mailer report <id>`), особо — ошибки и письма,
   не подтверждённые в Timeline.

Запрещено: создавать лиды/сделки/контакты/компании, менять стадию, воронку, ответственного
и любые поля CRM. Клиент (`bitrix_mailer/client.py`) технически блокирует такие вызовы —
не ослабляй эту защиту.

Тесты: `python3 -m unittest -v`
